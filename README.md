# РЕВЕРС — видео → промпт → кадры

Разбирает видео и достаёт из него промпт для видеомоделей: свет, цвет, оптика,
движение камеры, монтажный ритм. Плюс нарезка на кадры и выгрузка их архивом.

Анализ видео идёт целиком в браузере — файлы никуда не загружаются.

**Сайт:** https://sergei-dell.github.io/revers-lab/

## Устройство

Статическая сборка Next.js (`output: 'export'`), публикуется на GitHub Pages
из ветки `pages` workflow-ом `.github/workflows/pages.yml`. Сервера и базы нет.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000/revers-lab

## Что работает

Загрузка видео файлом, нарезка кадров, ZIP-архив, контактный лист, экспорт
отрезка, метрики, промпт RU/EN и негативный промпт. История разборов — в памяти
браузера (localStorage), только на этом устройстве.

## Чего нет в статической версии

- AI-описание сцены (требовало сервер с ключом OpenAI)
- загрузка видео по ссылке (требовала серверный прокси)
- общая история между устройствами (требовала PostgreSQL)

## Стек

Next.js 16, React 19, Tailwind 4.
