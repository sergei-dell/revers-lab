# РЕВЕРС — видео → промпт → кадры

Разбирает видео и достаёт из него промпт для видеомоделей: свет, цвет, оптика,
движение камеры, монтажный ритм. Плюс нарезка на кадры и выгрузка их архивом.

Анализ видео идёт целиком в браузере — файлы никуда не загружаются.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

Нужен файл `.env.local` с одной строкой, иначе проект не стартует:

```
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db
```

## Запуск на Vercel

Импортировать репозиторий, в Environment Variables добавить `DATABASE_URL`
с тем же значением. Настройки сборки менять не нужно.

## Что работает без настройки

Загрузка видео файлом, нарезка кадров, ZIP-архив, метрики, промпт RU/EN
и негативный промпт.

## Что требует настройки

| Возможность | Что нужно |
|---|---|
| История разборов | настоящий PostgreSQL в `DATABASE_URL` |
| AI-описание сцены | ключ `POLLINATIONS_API_KEY` |
| Вход на сайт | пароль `REVERS_PAROL` |

### Пароль на сайт

Сайт закрыт паролем: без него не открывается ни одна страница и не
отвечает ни один запрос к серверу. Пароль задаётся переменной
`REVERS_PAROL` — на Vercel в Settings → Environment Variables, у себя
в `.env.local`:

```
REVERS_PAROL=какой-нибудь-пароль
```

Если переменная не задана, сайт закрыт для всех: забытая настройка не
должна открыть сервис посторонним — ключ Pollinations на нём один.
Вход помнится месяц. В статической сборке для GitHub Pages замка нет:
там нет сервера, который проверил бы пароль (и ключа там тоже нет).

### AI-описание сцены

Идёт через Pollinations (`https://gen.pollinations.ai`, формат OpenAI chat
completions). В `.env.local` добавить:

```
POLLINATIONS_API_KEY=ключ с enter.pollinations.ai/keys
POLLINATIONS_MODEL=openai/gpt-5.4-mini
```

Ключ пишется как есть, без кавычек и без слова `Bearer`; приставки вроде
`sk-` или `pk-` не обязательны. Если в ключе есть знак `$` или `#`, Next.js
при загрузке `.env.local` срезал бы всё после него — поэтому значение читается
ещё и напрямую из файла, а в журнал сервера пишется строка `[enrich] …` с
разбором: откуда взят ключ, сколько в нём знаков и что помешало. Самого ключа
в журнале нет.

Модели уходит 6, 8, 12 или 16 кадров — выбор рядом с кнопкой «Описать кадры
моделью», по умолчанию 8, запоминается в браузере. Кадры берутся равномерно по
всей длине ролика. Сколько картинок принимает модель, сервер узнаёт из
`GET /models`; если выбрано больше, кнопка выключается, а рядом написано, какую
модель вписать в `POLLINATIONS_MODEL`. Под ответом видно, сколько снимались
кадры и за сколько ответила модель; то же пишется в журнал сервера.

`POLLINATIONS_MODEL` необязателен: без него берётся `openai/gpt-5.4-mini` —
vision-модель из списка `GET /models`, принимает до 10 картинок и умеет
`response_format`. Ключ читается только на сервере и в браузер не уходит.
Без ключа маршрут отвечает 501, локальный анализ работает как обычно.

## Две сборки из одного кода

Обычная — с сервером, базой и AI-описанием. Статическая, для GitHub Pages
(https://sergei-dell.github.io/revers-lab/), — `NEXT_PUBLIC_STATIC=1 npm run build`:
без сервера, история в памяти браузера, AI-описание и загрузка по ссылке скрыты.

Обновить сайт на Pages (ветка `pages` собирается из `main` одной командой):

```bash
node scripts/собрать-статику.mjs --push
```

Next.js 16, React 19, Tailwind 4, Drizzle ORM, PostgreSQL.
