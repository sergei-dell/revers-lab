# РЕВЕРС — поверх оригинала

Берёт трендовый ролик и готовит из него тренд для витрины. Ролик уходит в
Seedance **видео-основой** и задаёт всё: движение, камеру, тайминг, звук.
Меняются только лицо, тело и волосы, одежда, место и товар.

Один экран, пять шагов:

1. **Видео-основа** — загрузили ролик, сайт срезал чёрные поля и неподвижный
   интерфейс и пересобрал запись начисто: шум убран, резкость, высокий битрейт.
   Отдаёт основную версию и запасную поменьше.
2. **Фишка и что меняем** — одной строкой, в чём соль ролика, и переключатели
   подмен. Номера `@image` считаются сами.
3. **Claude пишет шаблон** — вручную (скачали пакет, отнесли в чат, вставили
   ответ) или автоматически по API.
4. **Генерация** — что в каком порядке грузить в SYNTX, оценка результата,
   записанные баги и счётчик испытания.
5. **Витрина** — архив тренда: основы, шаблон, список фото для клиента.

Ниже — свёрнутый блок «Ручная настройка шаблона»: моменты по времени и
шаблон, собранный кодом, без всякой нейросети.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000 и ввести пароль.

## Настройки

Всё живёт в `.env.local`. Обязательна только первая строка.

| Переменная | Зачем |
|---|---|
| `REVERS_PAROL` | пароль на вход; без него сайт закрыт для всех |
| `ANTHROPIC_API_KEY` | чтобы Claude писал шаблон сам; без ключа — только вручную |
| `REVERS_CLAUDE_MODEL` | какой моделью писать; по умолчанию `claude-sonnet-5` |
| `REVERS_CLAUDE_STUB` | `1` — отвечать заглушкой, не обращаясь к API (для проверок) |

### Пароль на сайт

Без пароля не открывается ни одна страница и не отвечает ни один запрос к
серверу. Если переменная не задана, сайт закрыт и для владельца: забытая
настройка не должна открыть сервис посторонним. Вход помнится месяц.

### Claude

Режим «Потом: автоматически» отправляет пакет разбора в Claude и получает
готовый шаблон. Без ключа кнопка неактивна и рядом написано, что Claude не
подключён, — тогда пакет скачивается кнопкой и относится в чат руками.

## Что где лежит

- `src/lib/osnova/` — вся работа с роликом: ffmpeg, обрезка, кадры, пакет,
  шаблон, переходник к генератору.
- `src/components/Revers2.tsx` — единственный экран.
- `.данные/` рядом с проектом — видео-основы и счётчик испытания. Обычные
  файлы, базы нет; в git не уходят.
- `ПРОЧТИ-claude.md` — задача для Claude. Один и тот же файл кладётся в пакет
  и идёт системным текстом при работе по API.
- `архив-заданий/` — прежние задания и макеты, для истории.

## Чего больше нет

Разбор ролика на промпт, нарезка на сцены и ДНК, метрики камеры и палитра,
описание кадров через Pollinations, история разборов в Postgres и
статическая сборка для GitHub Pages — всё убрано. Проверка показала, что
работает только путь «поверх оригинала»: Seedance видит само видео, и
пересказывать его словами незачем. История изменений осталась в git.

## Стек

Next.js 16 (App Router), React 19, Tailwind 4, TypeScript. На сервере —
`ffmpeg-static`, в браузере — `jszip` для архивов.
