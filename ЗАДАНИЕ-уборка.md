# ЗАДАНИЕ: РЕВЕРС — уборка, остаётся только «поверх оригинала»

Репозиторий РЕВЕРСА — папка `сервис`. Код в ответах не показывай.
**`.env.local` не трогай. `npm run dev` сам не запускай. Команды — не дольше 2 минут.
Коммит после каждого пункта.**

## Зачем
Проверено: работает только путь «поверх оригинала» (видео-основа + фото + шаблон).
Seedance сам видит видео, поэтому гены, метрики камеры, палитра и полная ДНК ему не нужны.
Всё лишнее удаляем — сайт должен стать маленьким и понятным. История останется в git.

**Если начато объединение трёх нарезок (гены + метрики в днк.json) — отменить,
незакоммиченное откатить.**

## Оставить (главный экран РЕВЕРСА 2, 5 блоков)
1. Видео-основа: загрузка, обрезка полей и интерфейса (ffmpeg на сервере), основа 1080 и запасная 720.
2. Фишка и что меняем (лицо, тело и волосы, одежда, место, товар, нумерация @image).
3. Claude пишет шаблон: «вручную» (пакет) и «автоматически» (Claude API).
4. Генерация: список загрузки для SYNTX, адаптер генератора (пока заглушка), оценка, баги, счётчик испытания.
5. Витрина: архив тренда.
Плюс свёрнутый блок «Ручная настройка шаблона (без Claude)» — моменты и шаблон кодом.
Плюс вход по паролю (замок).

## Как проверить
1. `npx tsc --noEmit` и `npm run build` — без ошибок (сборку запускай частями, если долго).
2. В коде нет импортов удалённого: поиск по `analyze`, `dnk`, `pollinations`, `drizzle`, `enrich` — пусто.
3. Синтетический ролик (как в прошлой проверке: 6 сцен с таймером, чёрные поля) → основа без полей,
   пакет из 7 пунктов, на кадрах таймер совпадает с подписью (±0,05 сек).
4. Вход по паролю работает в окне инкогнито.
5. Отчёт: сколько файлов и строк удалено, что осталось, что не проверил.
