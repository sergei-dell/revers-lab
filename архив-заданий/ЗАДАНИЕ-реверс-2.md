# ЗАДАНИЕ: РЕВЕРС 2 — «поверх оригинала»

Репозиторий РЕВЕРСА — папка `сервис`. Код в ответах не показывай.
**Файл `.env.local` не удаляй, не перемещай и не переименовывай.**
**`npm run dev` сам не запускай** — владелец запускает сам. Любая твоя команда — не дольше 2 минут.

Рядом с этим файлом:
- **`образец-реверс-2.html`** — макет. Пройди его: «Выбрать ролик» → переключатели → режимы
  «Сейчас: вручную» / «Потом: автоматически» в блоке 3 → генерация → оценка «Средне» с багом →
  «Отлично» → «На витрину» → оба свёрнутых блока внизу. Делай так же, в стиле РЕВЕРСА.
  Где макет и текст расходятся — прав макет.
- **`ПРОЧТИ-claude.md`** — инструкция для Claude. Кладётся в пакет как есть и используется
  как системный текст в автоматическом режиме.
- **`турник-поверх-оригинала-v3.txt`** — эталон шаблона, который дал лучший результат.

## Зачем

Проверено вручную: лучший результат даёт режим **«поверх оригинала»** — трендовый ролик
загружается в Seedance как видео-основа, а меняются только лицо, тело и волосы, одежда, место,
товар. РЕВЕРС переделываем под этот путь. Сейчас шаблон пишет Claude в чате (вручную),
потом — по API (автоматически). Строим один раз так, чтобы потом только включить режим.

## Главное правило: ничего старого не удалять

Режимы «Промпт», «ДНК ролика», карточка «Для Seedance», раскадровка, сцены, камера, свет, цвет,
«Скачать ДНК» — остаются рабочими, но **уходят в свёрнутый блок «Подробный разбор и другие
инструменты»** внизу экрана (по умолчанию закрыт). Код не переписывать, только переставить.
На главном экране — только новый путь из 5 блоков.

## 1. Видео-основа

После загрузки ролика сайт сам делает чистую основу (на сервере, через `ffmpeg-static` —
добавь зависимость; системный ffmpeg не предполагай):
- **Обрезка интерфейса**: автоматически найти неподвижные полосы сверху и снизу (интерфейс
  Instagram/TikTok, подписи, субтитры) и предложить рамку; рамку можно поправить вручную
  (перетаскиванием или полями). Обрезка применяется и к основе, и ко всем кадрам.
- **Основа 1080×1920**: шумоподавление, резкость, 30 к/с, H.264 High, высокий битрейт
  (ориентир: `hqdn3d=3:3:6:6`, `scale=…:flags=lanczos`, `unsharp=5:5:1.0`, `-crf 14`).
  Плюс **запасная 720×1280**. Обе — кнопками «Скачать».
- Проверки, как в макете: ✓ интерфейс обрезан, ✓ формат и длительность; **«!»** если после
  обрезки меньше 540 по ширине — «исходник мелкий, возьмите исходный файл ролика».
- Не вертикальный ролик — тоже работает, формат берётся из ролика.

## 2. Фишка и что меняем

- Поле «В чём фишка» (одна строка, можно по-русски).
- Переключатели: **Лицо, Тело и волосы, Одежда, Место, Товар**. У Одежды поле текста (EN),
  у Товара поле «что в оригинале заменяем». Номера `@image1…N` считаются по порядку
  включённых пунктов с картинкой (одежда — текст, без номера), как в макете.

## 3. Claude пишет шаблон — два режима

Переключатель **«Сейчас: вручную» / «Потом: автоматически»**, выбор запоминается.

**Вручную** — кнопка «Скачать пакет для Claude», архив `пакет-<имя>.zip`:
- `основа-1080x1920.mp4` (если больше 20 МБ — `основа-720x1280.mp4`);
- `раскадровка.jpg` — кадры каждые 0,5 сек листом, с таймкодами на каждом кадре;
- `кадры/` — ключевые кадры (начало, смены движения, конец) jpeg без интерфейса;
- `днк.json` — как сейчас в «Скачать ДНК» + найденные смены движения с таймкодами;
- `фишка.txt` — фишка, «что нельзя менять», моменты (из ручного блока, если заполнены),
  и раздел «Баги прошлой генерации», если они записаны (см. блок 4);
- `что-меняем.json` — включённые пункты, их номера @image, одежда, заменяемый предмет;
- `заготовка-шаблона.txt` — шаблон, собранный кодом (см. «Ручная настройка»);
- `ПРОЧТИ-claude.md` — файл как есть.
Ниже — большое поле «Шаблон от Claude», куда вставляется ответ.

**Автоматически** — кнопка «Отправить Claude»: сервер шлёт в Claude API (`@anthropic-ai/sdk`)
системным текстом `ПРОЧТИ-claude.md`, а сообщением — `фишка.txt`, `что-меняем.json`, `днк.json`
текстом и раскадровку + ключевые кадры картинками (видео Claude не принимает). Ответ —
в то же поле. Ключ `ANTHROPIC_API_KEY`, модель `REVERS_CLAUDE_MODEL` — из `.env.local`
(впиши в `.env.example`, саму `.env.local` не трогай). **Без ключа** кнопка неактивна,
рядом: «Claude не подключён — работайте вручную». Реальных запросов к API не делай —
проверь на заглушке.

## 4. Генерация и оценка

- **Вручную**: список «Загрузите в SYNTX в таком порядке» (@video1 — основа, далее @image по
  номерам из блока 2), подсказка настроек «9:16 · длительность ролика · Seedance 2.5»,
  кнопка «Копировать шаблон» (берёт текст из поля блока 3).
- **Автоматически**: кнопка «Отправить в Seedance · пробно» — пока **не подключено**:
  неактивна с надписью «Генератор не подключён». Сделай для этого отдельный модуль-адаптер
  с одной функцией (основа + картинки по порядку + шаблон + настройки → ссылка на видео),
  реализация — заглушка. Подключим позже.
- **Оценка**: Отлично / Средне — доработать / Плохо. При «Средне» и «Плохо» — поле
  «Что не так» и кнопка «Отправить Claude на доработку»: баг сохраняется в историю тренда;
  вручную — попадает в `фишка.txt` следующего пакета; автоматически — уходит в Claude вместе с
  текущим шаблоном с просьбой исправить.
- Счётчик **«испытание: N из 10»** — сколько разных трендов получили «Отлично».
  Хранить без базы Postgres (она у владельца не запущена): JSON-файл на диске сервера
  в папке данных РЕВЕРСА.

## 5. Витрина

Кнопка «На витрину» — активна только после «Отлично». Пока связи с витриной нет:
кнопка скачивает `тренд-<имя>.zip` — основа (обе версии), итоговый шаблон, `фото-для-клиента.json`
(какие фото просить у клиента и под какими номерами @image), пример результата, если
загружен. Позже это станет прямой отправкой в админку витрины.

## Свёрнутые блоки (по умолчанию закрыты)

1. **«Ручная настройка шаблона (без Claude)»**: поле «Что в кадре нельзя менять»; шкала
   времени со сменами движения (пунктир) и моментами; список моментов (время + что
   происходит, отметка «фишка», добавить/удалить); шаблон, собранный кодом, в формате
   эталона v3 (блоки и логика — как в функции `build()` макета); кнопки «Копировать» и
   «Подставить в блок 3».
2. **«Подробный разбор и другие инструменты»**: всё старое (см. «Главное правило»).

## Как проверить

1. Старые режимы открываются в свёрнутом блоке и работают как раньше; «Скачать ДНК» работает.
2. Ролик 384×848 с полосами сверху/снизу (сделай тестовый через ffmpeg: цветной фон +
   движущийся круг + неподвижные полосы с текстом) → рамка находится сама, основа 1080×1920
   и 720×1280 без полос; предупреждение «исходник мелкий».
3. Выключить «Место» → товар становится @image3 везде: блок 2, список загрузки, шаблон кодом.
4. «Скачать пакет для Claude» → в архиве все 8 пунктов, раскадровка с таймкодами.
5. Режим «автоматически» без ключа → кнопки неактивны с понятными надписями; с фиктивным ключом
   и заглушкой запроса — шаблон приходит в поле.
6. «Средне» + «long hair» → баг в истории; следующий пакет — баг в `фишка.txt`.
7. «Отлично» → счётчик +1, «На витрину» скачивает `тренд-<имя>.zip`.
8. Ширина 390 и 1440, без горизонтальной прокрутки.

Тестовые ролики — только сгенерированные ffmpeg, короткие; чужие не качай.
В конце — коммит и отчёт: что сделал, что проверил, что не проверил.
