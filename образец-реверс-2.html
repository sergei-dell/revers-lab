Макет РЕВЕРС 2. На виду только главный путь: ролик → фишка → Claude пишет шаблон → генерация → витрина. Блок «Claude» работает в двух режимах: сейчас — вручную (скачали пакет, отдали Claude в чат, вставили ответ, сгенерировали в SYNTX сами) и потом — автоматически (после подключения API Claude и Seedance всё идёт само, вы только ставите оценку). Всё старое не удалено — оно в двух свёрнутых блоках внизу. Попробуйте переключить режим в блоке 3.
