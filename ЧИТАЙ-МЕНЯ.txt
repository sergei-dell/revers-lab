КАК ЗАПУСТИТЬ САЙТ У СЕБЯ НА КОМПЬЮТЕРЕ
=======================================

ШАГ 1. Установить Node.js (один раз в жизни)
--------------------------------------------
Зайди на https://nodejs.org
Скачай большую зелёную кнопку слева (там написано LTS).
Установи как обычную программу: Далее - Далее - Готово.
Перезагружать компьютер не нужно.


ШАГ 2. Распаковать этот архив
------------------------------
Правой кнопкой по архиву -> "Извлечь всё".
Положи папку куда угодно, например на Рабочий стол.
ВАЖНО: запускать надо именно из распакованной папки, не из архива.


ШАГ 3. Запустить
-----------------
Windows:  два клика по файлу  ЗАПУСТИТЬ-Windows.bat
Mac:      два клика по файлу  ЗАПУСТИТЬ-Mac.command

Откроется чёрное окно с текстом. Это нормально.
В первый раз оно будет думать 1-3 минуты - скачивает нужные файлы.


ШАГ 4. Открыть сайт
--------------------
Открой браузер и набери:   localhost:3000/revers-lab

Всё. Сайт работает.


КАК ВЫКЛЮЧИТЬ
--------------
Просто закрой чёрное окно.
В следующий раз запуск будет быстрым, шаг с ожиданием не повторится.


ЕСЛИ НА MAC НЕ ОТКРЫВАЕТСЯ ФАЙЛ
--------------------------------
Открой программу "Терминал", напиши  chmod +x  (с пробелом в конце),
перетащи туда файл ЗАПУСТИТЬ-Mac.command и нажми Enter.
Потом снова два клика по файлу.


ЧТО РАБОТАЕТ СРАЗУ, А ЧТО НЕТ
------------------------------
Работает сразу:
  - загрузка видео с компьютера
  - нарезка на кадры, скачивание кадров и ZIP-архива
  - анализ света, цвета, движения камеры
  - готовый промпт на русском и английском + негативный промпт

  - история разборов - хранится в памяти этого браузера

Нет в этой версии (у сайта нет сервера):
  - AI-описание сцены нейросетью
  - загрузка видео по ссылке - скачай видео и загрузи файлом
  - история на других устройствах - она живёт только в одном браузере

Всё это можно доделать, если захочешь - просто скажи.
